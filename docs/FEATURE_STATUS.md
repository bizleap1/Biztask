# BizTask Feature Status Matrix (31 Features)

> **Classification Legend:**
> - `DONE_VERIFIED`: Implemented end-to-end, verified in code, and free of blocking defects.
> - `PARTIALLY_DONE`: Core or partial implementation exists, but missing spec requirements, roles, or has bugs.
